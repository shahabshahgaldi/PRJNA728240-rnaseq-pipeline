# Results Folder

This folder contains the main output files generated from the RNA-Seq differential expression (DE) analysis pipeline for the PRJNA728240 dataset.

## Contents

1. **DE_results_d2_vs_d0_withSymbols.csv**
   - Differential expression analysis results comparing day 2 (D2) vs day 0 (D0).
   - Contains gene identifiers, mapped gene symbols, log2 fold changes, statistical significance values (p-value, adjusted p-value), and other relevant DE metrics.

2. **DE_results_d6_vs_d0_withSymbols.csv**
   - Differential expression analysis results comparing day 6 (D6) vs day 0 (D0).
   - Contains gene identifiers, mapped gene symbols, log2 fold changes, statistical significance values (p-value, adjusted p-value), and other relevant DE metrics.

3. **filter_threshold_summary.csv**
   - Summary table showing results of low-count gene filtering.
   - Displays the number of genes retained for various count thresholds, along with the filtering criteria applied.

4. **normalized_counts.csv**
   - Normalized gene-level counts generated by DESeq2.
   - Provides normalized expression values across samples for downstream analysis and visualization.

5. **Volcano_d2_vs_d0.pdf**
   - Volcano plot visualization for the D2 vs D0 comparison.
   - Displays log2 fold change vs -log10(adjusted p-value), highlighting significant genes above defined thresholds.

6. **Volcano_d6_vs_d0.pdf**
   - Volcano plot visualization for the D6 vs D0 comparison.
   - Displays log2 fold change vs -log10(adjusted p-value), highlighting significant genes above defined thresholds.

## Notes
- All results were generated using the `01_DE_analysis_pipeline.R` script.
- Gene identifiers have been mapped to human-readable gene symbols where available.
- Significance thresholds for DE results: adjusted p-value < 0.05 and |log2FC| > 1.
